# Design Tokens

`shared/style.css`에 정의된 디자인 토큰의 문서화. 실제 정의는 CSS 파일에 있고, 이 문서는 토큰의 **의미와 사용 기준**을 설명한다.

토큰을 추가·변경할 때는 반드시 이 문서와 `shared/style.css`를 함께 수정한다. 토큰 수정은 사용자 승인 필요(`CLAUDE.md` §5 작업 중단 조건 4).

---

## 0. 사용 원칙

이 문서의 HEX 값은 토큰 의미를 설명하기 위한 **참조값**이다. HTML·SVG·CSS 작성 시 색상값을 직접 입력하지 않는다. 실제 코드에서는 반드시 `var(--color-*)`, `var(--svg-*)`, 또는 `currentColor`를 사용한다.

이 문서는 토큰의 의미와 사용 기준을 설명한다. 컴포넌트별 구체 적용 방식(어떤 클래스에 어떤 토큰을 쓰는지)은 `spec/component-catalog.md`를 따른다.

## 1. 색상 (Color)

### 1-1. 브랜드 레드

| 토큰 | HEX (참조) | 용도 |
|---|---|---|
| `--color-red` | `#E60012` | 브랜드 메인. 강조 텍스트·코어 박스 테두리·기준 식별 |
| `--color-red-deep` | `#B8000E` | 레드 어두운 변형. 강조 카드의 보조 텍스트 |
| `--color-red-soft` | `#FBE5E7` | 레드 배경. 단어 단위 하이라이트 underline |
| `--color-red-pale` | `#FFF5F6` | 레드 페일. 강조 카드 그라데이션 배경 |

#### 레드 사용 원칙

레드는 **롯데 브랜드성**과 **발표자가 반드시 짚어야 할 판단 지점**을 표시할 때만 사용한다.

**사용 가능**:
- 핵심 메시지
- 선택된 대안 (예: SAP S/4HANA 선택안)
- 기준 법인 또는 중앙 ERP 코어
- 핵심 KPI
- 위험 통제·성과 강조 (예: 다운타임 114h → 52h)

**사용 금지**:
- 장식용 라벨
- 모든 카드의 반복 강조
- 배경 전체 면적 채우기
- 의미 없는 아이콘 강조

구체적인 컴포넌트별 적용 기준은 `spec/component-catalog.md`를 따른다.

### 1-2. 페이퍼 / 배경

| 토큰 | HEX (참조) | 용도 | 상태 (v1.2) |
|---|---|---|---|
| `--color-paper` | `#FFFFFF` | **주 배경** — 슬라이드와 카드의 기본 흰색. 모든 톤(A·B·C)에서 주 톤 | 주 사용 |
| `--color-bg` | `#FBF9F4` | stage 바깥 배경 한정. 슬라이드 내부 배경으로는 절제 사용 | 절제 사용 |
| `--color-bg-warm` | `#F4EFE3` | (구) 큰 면적의 섹션 배경 | **폐기 — 사용 금지** |
| `--color-bg-cream` | `#F7F2E5` | **강조판 한정** — 메시지 박스·인용 박스·강조 카드 배경. 한 슬라이드에 1~2 영역만 사용 | 강조판 한정 |

#### 톤 사용 원칙 (v1.2 — cream 강등)

본 프로젝트의 주 톤은 **화이트(`--color-paper`) · 다크(`--color-graphite`) · 레드(`--color-red`)** 3색 중심이다.

- **주 배경**: `--color-paper` (모든 슬라이드 stage 기본)
- **다크 강조판**: `--color-graphite` (한 슬라이드 1개 제한, 본문 메인 영역 제외 — CLAUDE.md §3-1 정합)
- **레드 강조**: 핵심 메시지·KPI emph·강조 라벨 한정
- **cream 강조판**: 작은 영역의 보조 강조판으로만 (메시지 박스·인용 박스·강조 카드). 한 슬라이드에 1~2 영역만. 큰 면적·주 배경 사용 금지
- **`--color-bg-warm` 폐기**: 누런 톤이 본 프로젝트 의도(화이트·다크·레드)와 정합하지 않음. 신규 슬라이드 사용 금지

본 원칙은 시범 빌드 v2 평가 결과를 반영한 디자인 시스템 갱신이다.

### 1-3. 잉크 (Text)

| 토큰 | HEX (참조) | 용도 |
|---|---|---|
| `--color-ink-strong` | `#15171C` | 제목과 핵심 문장 |
| `--color-ink` | `#1F2229` | 일반 본문 |
| `--color-ink-soft` | `#4A4F58` | 부제·설명문·페이지번호 |
| `--color-ink-mute` | `#898E97` | 메타 정보·보조 라벨 |
| `--color-ink-faint` | `#B8BAC0` | 장식선·비활성 정보 |
| `--color-ink-ghost` | `#E0DDD3` | 매우 약한 배경 요소 |

#### 잉크 사용 원칙

- 제목과 핵심 문장: `--color-ink-strong`
- 일반 본문: `--color-ink`
- 부제와 설명문: `--color-ink-soft`
- 메타 정보와 보조 라벨: `--color-ink-mute`
- 장식선 또는 비활성 정보: `--color-ink-faint` 이하

**본문 텍스트에는 `--color-ink-faint`를 사용하지 않는다.** 발표 화면에서 연한 회색 텍스트의 가독성이 급격히 떨어진다.

| 토큰 | HEX (참조) | 용도 |
|---|---|---|
| `--color-graphite` | `#2A2D33` | 산업적이고 단단한 느낌이 필요한 도식 보더·강조선. 일반 본문 텍스트에는 사용하지 않음 |
| `--color-steel` | `#5C6068` | 설비·공정·비활성 연결선 등 산업적 보조 요소. 핵심 강조색으로 사용하지 않음 |
| `--color-olive` | `#7A6F4C` | 석유화학 플랜트 일러스트 (Tone B 산업 배경 페이지 한정) |

### 1-6. SVG 헬퍼

SVG 내부에서 사용하는 투명도 색상 토큰.

| 토큰 | 값 (참조) | 용도 |
|---|---|---|
| `--svg-line-faint` | `rgba(21, 23, 28, 0.07)` | 다이어그램 궤도선 |
| `--svg-line-soft` | `rgba(21, 23, 28, 0.14)` | 다이어그램 약한 보조선 |

**SVG 내부에서 직접 `rgba(...)`를 쓰지 않는다.** 필요한 투명도 색상은 `--svg-*` 토큰으로 먼저 정의한 뒤 사용한다.

### 2-3. 전역 타이포 스케일 토큰 (v1.6 신규 — GPT 강제 룰 검토 반영)

발표용 1920×1080 슬라이드 기준 최소 크기 강제. 페이지별 감으로 글자 크기 정하지 말고 본 토큰 우선 사용.

```css
:root {
  --fs-page-title: 58px;          /* 페이지 메인 제목 권장 — 최소 48px */
  --fs-page-title-min: 48px;       /* 페이지 제목 절대 최소 */
  --fs-section-title: 44px;
  --fs-card-title: 34px;           /* 카드 제목 권장 — 최소 30px */
  --fs-card-title-min: 30px;       /* 카드 제목 절대 최소 */
  --fs-card-body: 24px;            /* 카드 본문 권장 — 최소 22px */
  --fs-card-body-min: 22px;
  --fs-card-sub: 21px;             /* 보조 설명 권장 — 최소 20px */
  --fs-table-body: 28px;           /* 표 본문 권장 — 최소 26px */
  --fs-table-body-min: 26px;
  --fs-label: 18px;                /* 라벨·eyebrow 권장 */
  --fs-label-min: 16px;            /* 라벨 절대 최소 — 출처·페이지 번호 등 발표자 미독자는 예외 */
  --fs-eyebrow: 18px;
  --fs-kpi: 118px;                 /* KPI 숫자 권장 */
  --fs-kpi-min: 96px;              /* KPI 숫자 절대 최소 */
  --fs-kpi-small: 84px;            /* 보조 KPI */

  --icon-sm: 36px;                 /* 의미 전달용 아이콘 최소 */
  --icon-md: 46px;
  --icon-lg: 58px;

  --num-circle: 46px;              /* 목차 카드 번호 원 권장 */
  --num-circle-min: 42px;          /* 번호 원 절대 최소 */
}
```

**사용 원칙**: 페이지별 슬라이드 전용 CSS에서 위 토큰 우선 참조. `font-size: 14px` 같은 직접 값 사용 금지 (출처·페이지 번호·키보드 안내 같은 발표자 미독자 UI는 예외).

## 3. 스페이싱

### 3-1. 토큰

```
--sp-1: 4px    --sp-2: 8px    --sp-3: 12px
--sp-4: 16px   --sp-5: 24px   --sp-6: 32px
--sp-7: 48px   --sp-8: 64px   --sp-9: 80px
```

스페이싱 토큰은 컴포넌트 단위 padding·gap을 통해 적용한다.

### 3-2. 간격 사용 원칙

새 간격 값을 만들 때는 우선 `--sp-*` 토큰을 조합한다.

단, 슬라이드 레이아웃의 **큰 구조값**(예: 96px 패딩, 1920×1080 기준 좌우 배치값)은 컴포넌트 CSS에서 고정 px로 사용할 수 있다.

**임의의 미세값**(예: 37px, 53px, 71px)은 지양한다.

### 3-3. 슬라이드 패딩 (Tone별)

| Tone | `--slide-padding-x` | `--slide-padding-y` |
|---|---|---|
| A | 96px | 48px |
| B | 80px | 40px |
| C | 64px | 32px |

자세한 톤별 적용은 `spec/tone-system.md` 참조.

### 4-6. 빨강 사용 영역 (v1.5 신규 — 신호등 역할)

빨강은 **면이 아닌 신호등 역할**로만 사용한다.

**허용 영역**:
1. 핵심 단어 강조 (ERP 통합·M&A·S/4HANA·110국·2.8조 등 빨강 텍스트)
2. 작은 라벨·번호·포인트 (STEP 1·카드 번호·지도 핀·timeline 마커)
3. 얇은 선 또는 상단 바 (카드 상단 4px accent·표 마지막 열 좌측선·`.red-hero-block` 좌측 12px line)
4. 큰 숫자 watermark (06·05·1 등 6~12% opacity로 매우 연하게)
5. 활성 카드 표시 (`.card.is-active` red-soft 6% + 좌측 6px red line)

**금지 영역**:
- 화면 30% 이상 차지하는 큰 면 (좌측 40~50% red fill 패널)
- 한 슬라이드 빨강 강조 포인트 5개 초과
- 빨강 + 다크 동시 큰 면 사용 (시각 무게 충돌)

## 8. 색상 비율 가이드 (v1.5 신규 — GPT 검토 반영)

본 프로젝트는 학부 발표 35분 자료. 색상 비율은 다음을 권장한다:

| 색상 | 권장 비율 | 역할 |
|---|---|---|
| White / Paper | 70~80% | 기본 배경 |
| Graphite / Black | 15~22% | 제목·카드 헤더·구조선 |
| Red | 3~7% | 핵심 강조·번호·핀·얇은 선·핵심 단어 (면 X) |
| Cream / Light Gray | 5~10% | 보조 배경·데이터 카드·활성 표시 |

**기준 근거**: 롯데케미칼 로고 자체가 다색(빨강·녹색 액센트)이라 강한 단색 레드 배경과 충돌. 학부 발표 35분 동안 시각 피로 누적 회피.

### 4-2. Radius

```
--r-sm: 3px    --r-md: 6px    --r-lg: 12px
```

**radius 사용 원칙**: 과도하게 둥근 카드, pill형 대형 박스는 사용하지 않는다. 전체 톤은 산업 보고서형이므로 작은 radius를 기본으로 한다.

## 5. 토큰 추가 규칙

새 토큰이 필요할 때는 다음 절차를 따른다.

1. 기존 토큰으로 해결 가능한지 확인
2. 사용자에게 추가 사유 보고 (`CLAUDE.md` §5 작업 중단 조건 4)
3. 승인 후 `shared/style.css`와 이 문서에 동시 추가
4. 토큰 이름은 `--color-*`, `--font-*`, `--sp-*` 등 기존 prefix 규칙 따름
5. 한 슬라이드에만 쓰이는 토큰은 추가하지 않는다. 이 경우 해당 슬라이드 또는 컴포넌트의 클래스 내부에서 제한적으로 값을 정의한다. **색상은 예외 없이 기존 색상 토큰을 사용한다.**

## 6. 절대 금지

- 16진수 색상 하드코딩 (`#E60012` 같은 직접 사용) — 예외: `fill="none"`, `stroke="none"`
- `style="color: red"` 같은 인라인 색상
- 토큰에 없는 색상 임의 도입 (회색 그라데이션 5단계 등)
- Tailwind/Bootstrap 클래스 도입
- 슬라이드별 폰트 패밀리 변경
- **글로우형 box-shadow 또는 네온 효과용 rgba 색상 임의 사용** (일반적인 얕은 그림자는 기존 토큰 기반으로만 허용)
