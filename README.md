# ERP개론 팀프로젝트 — 롯데케미칼 SAP S/4HANA 도입 분석

광운대학교 경영학부 ERP개론 팀프로젝트 산출물. 롯데케미칼의 ERP 도입 사례를 Step 1~5로 분석하고,
발표는 웹 슬라이드로 제작했다.

**▶ 발표자료(웹): https://bapzzi.github.io/ERP_lottechemi/dist/presentation.html**

## 구성

| 경로 | 내용 |
|---|---|
| `docs/` | Step 1~5 보고서 (md · docx) |
| `report/` | Step 3-4-5 통합 최종보고서 (제출본 · pdf/docx/html) |
| `outline/` | 발표 구성 원고 — 슬라이드 단위 |
| `dist/` | 웹 발표자료 (HTML) |
| `shared/` | 공통 스타일·이미지 |
| `spec/` | 제작 규격 — 디자인 토큰 · 컴포넌트 카탈로그 · 톤 시스템 |
| `scripts/` | 슬라이드 생성·갱신 스크립트 (Python) |

발표자료는 Claude Code와 협업해 만들었다. 작업 규칙은 [`CLAUDE.md`](CLAUDE.md), 디자인·문안 규격은
[`spec/`](spec/)에 원천으로 두고 슬라이드 코드에 하드코딩하지 않는 방식을 썼다.
