## 1. 이 슬라이드의 역할

발표 전체의 첫 인상.
청중에게 핵심 메시지를 한 번에 던지고, 발표 전체에서 회수할 4개 핵심 수치(7개월·3사·10모듈·110개국)를 미리 노출한다.
결론 슬라이드(28번)와 호응하는 양 끝 — 표지에서 짧게 던지고, 결론에서 변주 문장으로 풀어서 닫는다.

## 2. 핵심 메시지

> 이 사례는 단순한 ERP 도입을 넘어,
> M&A 이후 3사를 하나의 운영 체계로 묶기 위한
> 통합 경영 기반 구축 프로젝트다.

**주의**: 현재 빌드된 HTML은 갱신 전 메시지 사용 중.
표지 카피 동기화 필요 (아래 §13 참조).

## 6. 시각화 방향

- 표지의 무게중심은 좌측 (제목·메시지) + 우측 (다이어그램)의 좌우 균형
- 좌측 텍스트는 위→아래로 시선 유도 (eyebrow → 제목 → 서브 → 메시지 → KPI)
- 우측 다이어그램은 본 발표의 핵심 도식(3사 통합 ERP)을 미리 노출 — 청중에게 "이 발표는 이 도식으로 풀어진다" 예고
- 배경 bg-molecule (석유화학 분자 클러스터 패턴) — 산업 특수성 시각 시그널
- KPI 4개는 발표 전체의 회수 지점 — 본문에서 다시 등장하는 수치만 표지에 노출

## 7. JS 인터랙션

- **reveal**: eyebrow → t-line(제목 2줄) → cover-sub → cover-message → key-line 순차 등장
- **--rev-delay**: 각 요소별 지연 (0.1s → 0.25s → 0.40s → 0.80s → 1.00s → 1.40s)
- **count**: key-line의 4개 수치 카운트업 (data-target="7", "3", "10", "110")
- **flow-dot · pulse-ring**: 다이어그램의 동적 표현 (CSS keyframe)
- 추가 JS 작성 금지. 기존 shared/script.js 기능만 사용.

## 8. 발표자 멘트 가이드

- **첫 문장**: "오늘은 롯데케미칼이 2017년에 SAP S/4HANA로 전환한 사례를 분석합니다."
- **핵심 설명**: "이 사례의 본질은 단순한 ERP 도입이 아니라, 2016년 M&A로 인수한 정밀화학·첨단소재를 포함해 3사를 하나의 운영 체계로 묶기 위한 통합 경영 기반 구축이었습니다."
- **다음 슬라이드 연결**: "이 발표가 그 결론을 어떤 4가지 근거로 입증할지부터 보겠습니다." → 02 논리 지도

## 9. 디자인 메모

- 좌측 텍스트와 우측 다이어그램의 시각 균형 유지 — 어느 한쪽이 압도하지 않게
- 표지 전체에서 레드는 t-em(제목 일부)·msg-hl(메시지 키워드)·kl-item--emph(KPI 강조)에만 사용
- bg-molecule은 0.07 opacity로 매우 약하게 — 정보 가독성 우선
- 헤더의 페이지 번호 "01 / 28"이 발표 시작 시점에 청중에게 분량 신호를 줌
